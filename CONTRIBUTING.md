# Contributing

Thanks for helping improve the ESP32 thermal print bridge.

## Ground rules

- Prefer small, focused PRs with a clear printer or board note
- Do not add SaaS, billing, or proprietary cloud clients here
- Test with `idf.py build` when changing firmware

## Setup

ESP-IDF >= 5.5, target `esp32p4` for the Waveshare ESP32-P4-NANO path.

## Reporting issues

Include board, printer model, USB VID/PID if known, and a serial log excerpt.
